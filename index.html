How it works

This is the algorithm from Folding Any Orthogonal Maze (Demaine, Demaine, Ku). Draw any orthogonal maze — walls on the edges of a grid — and the crease pattern below folds a flat square of paper into that maze: walls of uniform height extruded from a flat floor, using paper only 3× the maze footprint.

The trick is that the crease pattern is a tiling. Each grid vertex gets a local gadget chosen by which of its four incident edges carry walls — only six shapes are needed, up to rotation. Every gadget presents the same interface on each of its four sides: a ridge profile where a wall crosses, a floor profile where none does. Because interfaces always match, any combination of gadgets tiles into a valid, watertight crease pattern, in time linear in the maze size.

Red = mountain fold, blue = valley fold (printed side up); thin/light lines fold 90°, thick/dark lines fold 180°. Printing this page prints just the crease pattern. Fold all the 180° pleats flat first, then open the 90° walls.

Modeled on the authors’ original Origami Maze Font web app, whose source defined the reference gadget geometry, and on the companion maze puzzle font used for the text input above.
